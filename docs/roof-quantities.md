# Roof surface quantities

Guanacaste 3D keeps **plan area** (horizontal projection of the authored polygon)
separate from **roof finish/coverage area** (the built top surface).

- `FloorSlab.CalculateArea()` is the plan area and remains unchanged for
  floor schedules and spatial measurements.
- `RoofGeometry.SurfaceArea(slab)` includes the roof overhang generated by
  `RoofGeometry.WithOverhang`. For shed, gable and hip roofs, each planar facet
  has the specified pitch, so the actual top area is the built plan area divided
  by `cos(pitch)`. Flat roofs include their overhang but no slope factor.
- `FinishRules.FloorFinishArea` uses this coverage area for roofs and the
  plan area for ordinary floor slabs.
- `BudgetCalculator` prices `ROOF_AREA` by actual coverage area rather than
  the smaller authored boundary projection. Prices remain editable placeholders.

The result measures the exposed **top surface only**. It does not include
fascia, soffits, flashing, overlaps, waste, openings, or manufacturer-specific
ordering factors. Those need separate items in a professional cost estimate.
The calculation does not change project schema or saved geometry.
