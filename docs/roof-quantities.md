# Roof surface quantities

Guanacaste 3D keeps **plan area** (horizontal projection of the authored polygon)
separate from **roof finish/coverage area** (the built top surface).

- `FloorSlab.CalculateArea()` is the plan area and remains unchanged for
  floor schedules and spatial measurements.
- `RoofGeometry.SurfaceArea(slab)` includes the roof overhang generated by
  `RoofGeometry.WithOverhang`. For shed, gable and hip roofs, each planar facet
  has the specified pitch, so the actual top area is the built plan area divided
  by `cos(pitch)`. Flat roofs include their overhang but no slope factor.
- `FinishRules.FloorFinishArea` uses this coverage area for roofs and the
  plan area for ordinary floor slabs.
- `BudgetCalculator` prices `ROOF_AREA` by actual coverage area rather than
  the smaller authored boundary projection. Prices remain editable placeholders.

The result measures the exposed **top surface only**. It does not include
fascia, soffits, flashing, overlaps, waste, openings, or manufacturer-specific
ordering factors. Those need separate items in a professional cost estimate.
The calculation does not change project schema or saved geometry.

## Detailed roof quantities CSV

`RoofQuantitySchedule.ToCsv(document)` exports one row per roof, ordered by level and
stable roof identifier. Columns include the original horizontal plan area, covered
horizontal area after supported overhangs, true top-surface area, pitch, shape and
projected roof perimeter. A final `RoofName` column identifies each roof without
reordering the existing numeric columns. Values use invariant decimal punctuation,
and user-controlled level and roof names are quoted and escaped for CSV. Labels
beginning with spreadsheet formula operators (`=`, `+`, `-`, `@`), optionally after
whitespace, receive a leading apostrophe to prevent formula execution when
opened in spreadsheet software. The same CSV quoting rule now protects user-authored
level names in wall quantity reports and text fields in saved schedules, while
legitimate signed numeric schedule values remain numeric. This reduces common
spreadsheet-formula injection risks; importing untrusted CSV into other software
still warrants care. Ordinary floor slabs are excluded.

`RoofGeometry.ProjectedPerimeter` measures the **horizontal footprint boundary**
of the built roof, including overhangs. It is **not** the length of installed gutters,
fascia, ridge caps or sloping rake trims. Those require explicit edge classification
and 3D segment measurements before they can be priced accurately.
