Why Guanacaste 3D

01 / MODEL

Architectural elements

Work with levels, walls, hosted openings, rooms and slabs in a shared document.

02 / COORDINATE

Plans and 3D views

Navigate linked plan, 3D and documentation workspaces backed by the same project.

03 / REUSE

Explore quantities, view organization, schedules and drawing sheets in the technical preview.

Connect supported external or local AI providers with your own credentials, when configured.

Get started

From download to your first model.

Guanacaste 3D is a Windows desktop program. Published portable releases are available from the official GitHub releases page.

Check latest public release ↗
  1. Open the releases page and choose a published Windows x64 ZIP, if available.
  2. Extract the complete archive into a folder.
  3. Launch Guanacaste3D.Desktop.exe and explore the sample project.

The app is an unsigned technical preview. Review release notes, verify checksums when provided and keep backups of important projects. Do not use it for certified engineering output.
